PDF Tools v1.0.5

OCR accuracy and review update.

- Increased scanned-page OCR render resolution to 5.5x, with page-size based on PDF points and source image density.
- Added grayscale histogram autocontrast and high-quality enlargement before first-pass OCR.
- Restored the source Streamlit workflow's first-pass minimum word confidence of 10.
- Preserved per-word confidence scores and added per-cell confidence diagnostics.
- Improved row grouping with stable median anchors to reduce drift between columns.
- Added targeted cell-level OCR retries using multiple page segmentation modes and an adaptive-threshold variant.
- Added cautious decimal punctuation recovery: a column pattern alone cannot change a cell; a high-confidence image re-read must confirm the same digits first.
- Added safe removal of leading OCR '=' or '|' artefacts only when the remainder is a valid numeric token.
- Added an OCR Review worksheet for low-confidence, malformed numeric and supported arithmetic diagnostics.
- Arithmetic checks are diagnostic only. They never change, replace, or repair values in Page_N worksheets.
- Arithmetic diagnostics are enabled only when a Plan Summary Report layout is detected; unrelated documents do not receive assumed formula checks.
- Kept the flat GitHub Pages repository-root structure and browser-local PDF processing.

Validation:
- JavaScript syntax checks passed for every application module.
- ZIP integrity and root-only structure checks passed.
- Sample source PDF and previous XLSX were inspected to guide the changes.
- The full GitHub Pages browser workflow and Paddle-free Tesseract.js network loading were not executable in this environment; live browser verification remains required.
