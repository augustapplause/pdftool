PDF Tools v1.0.7

Image-resampling parity release.

- Implements separable Lanczos-3 resizing instead of browser Canvas smoothing.
- Uses Python-compatible integer truncation for target image dimensions.
- Aligns Tesseract.js OEM selection with the original --oem 3 configuration using OEM.DEFAULT.
- Removes forced 300 DPI, which was not present in the original Python configuration.
- Adds optional diagnostic ZIP containing source column crops, exact OCR input images, raw TSV and timings.
- Preserves the original Streamlit extraction and recovery sequence.
- Arithmetic diagnostics remain warnings only; no extracted values are changed by arithmetic checks.

All files are at the repository root. See README.md for deployment and diagnostic-mode instructions.
